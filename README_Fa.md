یک سیستم سبک، خودکار و امن برای مدیریت گواهینامه‌های SSL در سرورهای لینوکس. این پروژه ابزارهای **Certbot**، **Nginx** و یک **ربات اختصاصی تلگرام** را یکپارچه می‌کند تا بتوانید گواهینامه‌های خود را مستقیماً از طریق چت تلگرام یا منوی ساده ترمینال (CLI) مدیریت، تمدید و دانلود کنید یا وضعیت آن‌ها را بسنجید.

---

## ✨ قابلیت‌ها و ویژگی‌ها

- **🤖 اتصال کامل به ربات تلگرام:**
  - منوهای شیشه‌ای تعاملی (Inline Keyboard) با دستورات `/start`، `/status`، `/renew`، `/newcert` و `/download`.
  - امکان بررسی وضعیت تاریخ انقضا و مسیر هر دامنه به صورت جداگانه.
  - تمدید انتخابی گواهینامه برای دامنه مورد نظر.
  - ارسال مستقیم فایل‌های کلید و گواهینامه (`fullchain.pem` و `privkey.pem`) به داخل چت تلگرام.
  - ارسال نوتیفیکیشن و اعلان خودکار پس از تمدید دوره‌ای.
- **🛡️ سازگاری کامل با Nginx و فال‌بک پنل 3X-UI:**
  - هماهنگی کامل با ریورس پروکسی‌ها و سناریوهای Fallback پنل‌ها (Decoy Page).
  - پشتیبانی از گواهینامه‌های استاندارد و Wildcard.
- **💻 منوی مدیریت در ترمینال (CLI):**
  - دسترسی سریع به منوی مدیریت سرور تنها با تایپ دستور `ssl`.
- **🌐 پشتیبانی از پروکسی داخلی:**
  - قابلیت تعریف HTTP/HTTPS Proxy برای سرورهایی که در شبکه محدود یا تحریم هستند.
- **⏰ تمدید خودکار و هوشمند:**
  - تنظیم خودکار Cron Job برای بررسی و تمدید گواهینامه‌ها دو بار در روز (ساعت ۱۲ ظهر و ۱۲ شب).

## 📦 نحوه نصب و راه‌اندازی

دستور زیر را با دسترسی روت (`root`) روی سرور لینوکسی خود اجرا کنید تا اسکریپت نصب و پیکربندی ربات اجرا شود:

```bash
bash <(curl -fsSL https://github.com/Plus98ir/Auto_ssl-telegram_bot/releases/latest/download/install.sh)

```

در طول مراحل نصب، اسکریپت موارد زیر را از شما می‌پرسد:

تنظیم اختیاری پروکسی HTTP/HTTPS (در صورت نیاز به عبور از محدودیت‌ها).

توکن ربات تلگرام و Chat ID ادمین (اختیاری؛ در صورت تمایل می‌توانید رد کنید).

ایمیل شما برای ثبت‌نام در Certbot و دریافت هشدارهای مربوط به دامنه.

🛠️ راهنمای استفاده
۱. دستورات ربات تلگرام
پس از فعال‌سازی و اجرای سرویس ربات، کافیست دستور /start را برای ربات بفرستید تا پنل کنترل باز شود:

📊 وضعیت (Status): مشاهده تاریخ انقضا و مسیر فایل‌های هر دامنه با دکمه‌های شیشه‌ای.

🔄 تمدید (Renew): انتخاب دامنه مورد نظر و تمدید دستی آن در لحظه.

➕ گواهینامه جدید (New Cert): صدور گواهینامه جدید برای دامنه (مثال: example.com/newcert).

⬇️ دانلود (Download): انتخاب دامنه و دریافت مستقیم فایل‌های SSL در تلگرام.

۲. منوی خط فرمان در سرور (CLI)
در هر زمان که وارد محیط ترمینال سرور شدید، تنها با تایپ دستور زیر می‌توانید منوی مدیریت را باز کنید:

Bash
ssl
⚙️ نمونه کانفیگ Nginx برای فال‌بک (Fallback)
اگر در کنار این سیستم از پنل‌هایی مانند 3X-UI استفاده می‌کنید و می‌خواهید ترافیک ناشناخته یا وب معمولی به یک صفحه Decoy (مثلاً صفحه گیمینگ یا فایل HTML روی پورت داخلی 8040) هدایت شود، می‌توانید از این نمونه کانفیگ سبک در Nginx استفاده کنید:

Nginx
server {
    listen 127.0.0.1:8040;
    server_name yourdomain.com [www.yourdomain.com](https://www.yourdomain.com);
    
    root /var/www/html;
    index index.html;

    location / {
        try_files $uri$uri/ =404;
    }
}
